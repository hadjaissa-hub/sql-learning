# 📚 SQL — База SQL

## 🎯 Что я изучил

В этом уроке ты изучил **базовые конструкции для получения и фильтрации данных из таблицы**.

Ты научился:

* выбирать нужные столбцы;
* фильтровать строки по условиям;
* сортировать результаты;
* ограничивать количество строк;
* искать текст по шаблону;
* работать с диапазонами;
* проверять значение сразу по нескольким вариантам.

---

## 🧠 Главные понятия

### `SELECT`

Выбирает данные из таблицы.

```sql id="9d0dy7"
SELECT first_name, salary
FROM employees;
```

`SELECT *` — выбрать **все столбцы**:

```sql id="8l5lcz"
SELECT *
FROM employees;
```

### `WHERE`

Фильтрует строки по условию.

```sql id="j52a3x"
SELECT *
FROM employees
WHERE salary > 3000;
```

### Операторы сравнения

| Оператор | Значение         |
| -------- | ---------------- |
| `=`      | равно            |
| `<>`     | не равно         |
| `>`      | больше           |
| `<`      | меньше           |
| `>=`     | больше или равно |
| `<=`     | меньше или равно |

### `AND` / `OR`

Позволяют объединять несколько условий.

```sql id="h3dj7f"
WHERE age > 25 AND salary > 3000
```

```sql id="cm08r9"
WHERE department_id = 1 OR department_id = 2
```

### `ORDER BY`

Сортирует результат.

* `ASC` — по возрастанию
* `DESC` — по убыванию

```sql id="0x1h8e"
ORDER BY salary DESC;
```

Можно сортировать по нескольким столбцам:

```sql id="m4j4sj"
ORDER BY department_id ASC, salary DESC;
```

### `LIMIT`

Ограничивает количество возвращаемых строк.

```sql id="4o5m7c"
LIMIT 5;
```

### `LIKE`

Ищет текст по определённому шаблону.

```sql id="c7v0i3"
WHERE first_name LIKE 'A%';
```

`%` означает **любое количество символов**.

Например, `'A%'` → имена, начинающиеся с `A`.

### `BETWEEN`

Проверяет, находится ли значение в определённом диапазоне.

```sql id="z2j8b0"
WHERE salary BETWEEN 3000 AND 5000;
```

### `IN`

Проверяет, входит ли значение в список.

```sql id="q0w7nf"
WHERE department_id IN (1, 3, 5);
```

---

## 📝 Основной синтаксис

Общий базовый запрос:

```sql id="w4x4y4"
SELECT column1, column2
FROM table_name
WHERE condition
ORDER BY column ASC
LIMIT number;
```

---

## 🔑 Важные команды / конструкции

* `SELECT` — выбирает столбцы.
* `SELECT *` — выбирает все столбцы.
* `FROM` — указывает таблицу.
* `WHERE` — фильтрует строки.
* `AND` — все условия должны быть истинными.
* `OR` — достаточно выполнения одного из условий.
* `ORDER BY` — сортирует результат.
* `ASC` — по возрастанию.
* `DESC` — по убыванию.
* `LIMIT` — ограничивает количество строк.
* `LIKE` — поиск по шаблону.
* `%` — любое количество символов в `LIKE`.
* `BETWEEN` — проверка диапазона.
* `IN` — проверка значения среди нескольких вариантов.
* `AS` — задаёт псевдоним (алиас) для столбца или таблицы.
* `DISTINCT` — убирает повторяющиеся значения из результата.
* `NOT IN` — проверка, что значение не входит в указанный список.

## 💡 Примеры

### Выбрать сотрудников с зарплатой больше 3000

```sql id="y1v0r2"
SELECT first_name, salary
FROM employees
WHERE salary > 3000;
```

### Найти сотрудников старше 30 лет и отсортировать по зарплате

```sql id="p8m8cp"
SELECT *
FROM employees
WHERE age > 30
ORDER BY salary DESC;
```

### Найти имена, начинающиеся с `A`

```sql id="8d1k8m"
SELECT *
FROM employees
WHERE first_name LIKE 'A%';
```

### Найти сотрудников с зарплатой от 3000 до 5000

```sql id="b7f8tq"
SELECT *
FROM employees
WHERE salary BETWEEN 3000 AND 5000;
```

### Найти сотрудников из нескольких отделов

```sql id="3j2h4m"
SELECT *
FROM employees
WHERE department_id IN (1, 2, 5);
```

### Получить 5 самых высокооплачиваемых сотрудников

```sql id="6v0c2n"
SELECT first_name, salary
FROM employees
ORDER BY salary DESC
LIMIT 5;
```
