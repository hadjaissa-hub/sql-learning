# 📚 SQL — Агрегатные функции

## 🎯 Что я изучил

Ты изучил **агрегатные функции SQL** — функции, которые позволяют получить **одно итоговое значение из нескольких строк**.

Например, можно посчитать количество сотрудников, узнать общую сумму зарплат, среднюю зарплату, минимальную и максимальную зарплату.

---

## 🧠 Главные понятия

### `COUNT()`

Считает количество строк или значений.

```sql
COUNT(*)
```

`COUNT(*)` — считает **все строки**.

---

### `SUM()`

Считает сумму значений столбца.

```sql
SUM(salary)
```

Например, общая сумма всех зарплат.

---

### `AVG()`

Вычисляет среднее значение.

```sql
AVG(salary)
```

Например, средняя зарплата сотрудников.

---

### `MIN()`

Находит минимальное значение.

```sql
MIN(salary)
```

---

### `MAX()`

Находит максимальное значение.

```sql
MAX(salary)
```

---

## 📝 Основной синтаксис

Общий шаблон:

```sql
SELECT AGGREGATE_FUNCTION(column_name)
FROM table_name;
```

Например:

```sql
SELECT AVG(salary)
FROM employees;
```

---

## 🔑 Важные команды / конструкции

| Функция       | Что делает               |
| ------------- | ------------------------ |
| `COUNT(*)`    | Считает количество строк |
| `SUM(column)` | Считает сумму            |
| `AVG(column)` | Считает среднее значение |
| `MIN(column)` | Находит минимум          |
| `MAX(column)` | Находит максимум         |

### Основные конструкции:

```sql
COUNT(*)
SUM(salary)
AVG(salary)
MIN(salary)
MAX(salary)
```

Можно использовать **несколько агрегатных функций в одном `SELECT`**:

```sql
SELECT
    COUNT(*),
    SUM(salary),
    AVG(salary),
    MIN(salary),
    MAX(salary)
FROM employees;
```

---

## 💡 Примеры

### Посчитать количество сотрудников

```sql
SELECT COUNT(*)
FROM employees;
```

### Получить общую сумму зарплат

```sql
SELECT SUM(salary)
FROM employees;
```

### Получить среднюю зарплату

```sql
SELECT AVG(salary)
FROM employees;
```

### Найти минимальную и максимальную зарплату

```sql
SELECT
    MIN(salary),
    MAX(salary)
FROM employees;
```

### Получить всю статистику сразу

```sql
SELECT
    COUNT(*) AS employee_count,
    SUM(salary) AS total_salary,
    AVG(salary) AS average_salary,
    MIN(salary) AS minimum_salary,
    MAX(salary) AS maximum_salary
FROM employees;
```

Здесь `AS` используется для того, чтобы дать результатам **понятные названия**.

**Главная мысль урока:** агрегатные функции позволяют превратить множество строк в **итоговую статистику**.
